# Ferhat Kara - Kişisel Web Sitesi

Bu proje, Marmara Üniversitesi Bilgisayar Mühendisliği öğrencisi Ferhat Kara'nın web programlama dersinin haftalık ödevlerini içeren kişisel web sitesidir. Site, HTML, CSS ve JavaScript kullanarak geliştirilmiştir.

## Özellikler

- **Ana Sayfa**: Siteye genel bakış ve haftalık ödevlere bağlantılar.
- **Hakkımda**: Kişisel bilgiler ve özgeçmiş.
- **İlgi Alanlarım**: Hobiler ve ilgi alanları.
- **İletişim**: İletişim bilgileri ve formu.
- **Haftalık Ödevler**: Hafta 1'den Hafta 8'e kadar ders içerikleri.
  - Hafta 1: Giriş ve Temel Kavramlar
  - Hafta 2: HTML Yapısı ve Etiketler
  - Hafta 3: CSS Temelleri ve Seçiciler
  - Hafta 4: Flexbox ve Grid
  - Hafta 5: Responsive Tasarım
  - Hafta 6: JavaScript Temelleri
  - Hafta 7: Etkileşimli Öğeler
  - Hafta 8: Final Projesi

## Kurulum ve Çalıştırma

Bu proje herhangi bir sunucu gerektirmez. Sadece bir web tarayıcısı ile çalıştırılabilir.

1. Bu repository'yi klonlayın:
   ```
   git clone https://github.com/ferhatkaraa/ferhatkaraa.github.io.git
   ```

2. Ana dizindeki `index.html` dosyasını bir web tarayıcısında açın.

## Kullanım

- Ana sayfadan haftalık ödevlere göz atabilirsiniz.
- Navigasyon menüsü ile diğer sayfalara gidebilirsiniz.
- Sayfalar responsive tasarımla mobil cihazlarda da uyumludur.

## Teknolojiler

- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (ES6+)
